<h1>Neovim configuration</h1>

## About the project

The repository contains my personal files to configure Neovim as a text editor.

The configuration uses [LazyVim](https://www.lazyvim.org).
The initial setup was created using the starter template found on [Github](https://github.com/LazyVim/starter).

More information on the setup and configuration of [LazyVim]
can be found in the [documentation](https://lazyvim.github.io/installation).

*This configuration should be considerd work in progress.*
